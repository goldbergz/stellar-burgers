# Stellar Burgers

Одностраничное приложение для сборки бургеров, созданное на React, TypeScript, Redux Toolkit и React Router.

## Возможности

- Конструктор бургеров с выбором ингредиентов
- Просмотр деталей ингредиента в модальном окне и на отдельной странице
- Оформление заказа для авторизованных пользователей
- Публичная лента заказов со статистикой
- Аутентификация пользователей: регистрация, вход, выход
- Восстановление и сброс пароля
- Защищённые страницы профиля
- Личная история заказов
- Управление состоянием через Redux Toolkit
- Storybook для разработки и просмотра UI-компонентов

## Технологии

- React 18
- TypeScript
- Redux Toolkit
- React Router v6
- Webpack 5
- Storybook 7
- ESLint + Prettier

## Маршрутизация

В приложении настроены следующие основные маршруты:

- `/` — конструктор бургеров
- `/feed` — публичная лента заказов
- `/login` — вход
- `/register` — регистрация
- `/forgot-password` — восстановление пароля
- `/reset-password` — сброс пароля
- `/profile` — профиль пользователя
- `/profile/orders` — заказы авторизованного пользователя
- `/ingredients/:id` — детали ингредиента
- `/feed/:number` — детали публичного заказа
- `/profile/orders/:number` — детали личного заказа

Для деталей ингредиентов и заказов поддерживается открытие через модальные окна поверх текущей страницы.

## Управление состоянием

Redux store объединяет следующие slices:

- `ingredients` — загрузка и хранение ингредиентов
- `auth` — аутентификация и состояние текущего пользователя
- `orders` — создание и история пользовательских заказов
- `feed` — данные публичной ленты заказов
- `burgerConstructor` — текущее состояние собираемого бургера

## Работа с API

Приложение использует базовый URL backend API из переменной окружения `BURGER_API_URL`.

Реализованы следующие API-сценарии:

- получение списка ингредиентов
- загрузка публичной ленты заказов
- загрузка заказов авторизованного пользователя
- оформление заказа
- регистрация и вход
- получение и обновление данных текущего пользователя
- выход из аккаунта
- обновление токена при истечении `accessToken`
- запрос на сброс пароля

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

При необходимости создайте локальный файл окружения и укажите базовый URL API:

```env
BURGER_API_URL=https://your-api-url
```

### 3. Запуск проекта

```bash
npm start
```

Приложение запускается через Webpack Dev Server.

## Доступные скрипты

```bash
npm start            # запуск dev-сервера
npm run storybook    # запуск Storybook на порту 6006
npm run build-storybook
npm run lint
npm run lint:fix
npm run format
```

## Storybook

В проекте есть истории для многих UI-компонентов, что упрощает изолированную разработку и проверку состояний интерфейса.

Запуск:

```bash
npm run storybook
```

## Особенности аутентификации

- `accessToken` хранится в cookies
- `refreshToken` хранится в `localStorage`
- Для страниц профиля используются защищённые маршруты
- Для страниц авторизации и восстановления пароля используются guest-only маршруты
